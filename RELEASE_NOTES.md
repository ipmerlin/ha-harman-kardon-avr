Первая предварительная версия интеграции **Harman Kardon AVR 151S** для Home Assistant.

- Добавление и перенастройка через интерфейс HA на русском и английском.
- Включение, выключение, пошаговая громкость и выбор входов по Ethernet.
- При недоступной сети: однократная обученная команда Power On через Broadlink
  с ожиданием появления TCP, по умолчанию до 45 секунд.
- Кнопка переключения mute и отдельный датчик доступности Ethernet.

Локально пройдены 21 тест транспорта/автомата состояний, 12 тестов формы с
каждой из двух библиотек схем, проверка линтером и проверка архива/SHA-256.

В Linux CI пройдены ещё 10 тестов с Home Assistant 2026.10.2 / Python 3.14,
HACS validation и Hassfest. Тесты HA используют моки ресивера и ИК-передатчика.

**Ограничения:** физический ресивер и Broadlink не проверены. Состояние
медиаплеера предполагаемое: TCP не предоставляет
достоверной обратной связи о питании, входе и громкости.

В HACS добавьте пользовательский репозиторий
`https://github.com/ipmerlin/ha-harman-kardon-avr`, категория Integration.
Для предварительного релиза включите отображение предварительных версий.
Для ручной установки распакуйте `custom_components/hk_avr` из приложенного ZIP
в `/config/custom_components/hk_avr` и перезапустите HA.

Перед включением из глубокого сна обучите Broadlink отдельной команде
**Power On**, не Power Toggle. Пошаговая инструкция находится в README.
