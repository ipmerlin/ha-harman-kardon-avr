Предварительная версия **0.3.0** интеграции Harman Kardon AVR 151S для Home Assistant.

- Добавлен выбор **Xiaomi IR Local** (`xiaomi_ir`) рядом с Broadlink для ИК-включения.
- Используется сущность `remote` и обученная команда `device` / `command` из Xiaomi.
- Токен Xiaomi не требуется вводить в интеграции AVR.
- Старые настройки Broadlink и идентификаторы сущностей сохраняются.
- Выбрать Xiaomi можно через «Перенастроить» после обновления и перезапуска HA.
- Для ИК-передачи `last_command_transport` теперь равен `infrared`.

Проверки версии описаны в VALIDATION.md и GitHub Actions.

Тесты HA используют настоящий Home Assistant с моками ресивера и ИК-передатчика.

**Ограничения:** совместное пробуждение настоящих Xiaomi IR и AVR 151S не проверено. Состояние
медиаплеера предполагаемое: TCP не предоставляет
достоверной обратной связи о питании, входе и громкости.

В HACS добавьте пользовательский репозиторий
`https://github.com/ipmerlin/ha-harman-kardon-avr`, категория Integration.
Для предварительного релиза включите отображение предварительных версий.
После обновления перезапустите HA; добавлять устройство заново не нужно.
Для ручной установки распакуйте `custom_components/hk_avr` из приложенного ZIP
в `/config/custom_components/hk_avr` и перезапустите HA.

Перед включением из глубокого сна обучите выбранный ИК-пульт отдельной команде
**Power On**, не Power Toggle. Пошаговая инструкция находится в README.
