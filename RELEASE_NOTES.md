Предварительная версия **0.2.0** интеграции Harman Kardon AVR 151S для Home Assistant.

- Добавлены 16 сетевых кнопок: Play/Pause, следующий/предыдущий трек, перемотка,
  стрелки, OK, Back, Home, Info, Options и Sleep. Старая кнопка mute сохраняется.
- Добавлен видимый список входов и сущность сетевого пульта для автоматизаций.
- Стандартные действия медиаплеера для Play/Pause и смены треков.
- Сетевой пульт отправляет только Ethernet-команды, без ИК-подмены.
- Настройки и существующие идентификаторы 0.1.0 сохраняются.

Проверки версии описаны в VALIDATION.md и GitHub Actions.

Тесты HA используют настоящий Home Assistant с моками ресивера и ИК-передатчика.

**Ограничения:** физическая работа новых команд на AVR 151S не проверена. Состояние
медиаплеера предполагаемое: TCP не предоставляет
достоверной обратной связи о питании, входе и громкости.

В HACS добавьте пользовательский репозиторий
`https://github.com/ipmerlin/ha-harman-kardon-avr`, категория Integration.
Для предварительного релиза включите отображение предварительных версий.
После обновления с 0.1.0 перезапустите HA; добавлять устройство заново не нужно.
Для ручной установки распакуйте `custom_components/hk_avr` из приложенного ZIP
в `/config/custom_components/hk_avr` и перезапустите HA.

Перед включением из глубокого сна обучите Broadlink отдельной команде
**Power On**, не Power Toggle. Пошаговая инструкция находится в README.
