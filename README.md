# Harman Kardon AVR 151S для Home Assistant

Пользовательская интеграция с настройкой через интерфейс HA и включением из
глубокого сна через уже подключённый **Broadlink**. После пробуждения управление
продолжается по локальному Ethernet, без облачного API.

**Версия 0.2.0:** сборка для испытаний. Исходники опубликованы в
[ipmerlin/ha-harman-kardon-avr](https://github.com/ipmerlin/ha-harman-kardon-avr).
Физический AVR 151S этой сборкой пока не проверен. Результаты автоматических
проверок и их ограничения — в [VALIDATION.md](VALIDATION.md).
Минимальная заявленная версия HA: 2025.12.

[Предварительные релизы и архивы](https://github.com/ipmerlin/ha-harman-kardon-avr/releases)

## Что доступно

| Сущность | Действия и смысл |
| --- | --- |
| Медиаплеер | Включение, выключение, громкость шагами, вход, Play/Pause, предыдущий/следующий трек |
| Список «Вход» | Выбор источника непосредственно на странице устройства |
| 17 кнопок | Mute, воспроизведение, перемотка, навигация по меню и Sleep |
| «Сетевой пульт» | `remote.send_command` для Ethernet-команд и последовательностей |
| Датчик «Доступность Ethernet» | Возможность TCP-соединения с заданным адресом и портом |

Увеличение/уменьшение громкости не задаёт абсолютную громкость. В списке входов
используются имена протокола: Disc, STB, Cable Sat, Media Server, DVR, Radio,
TV, USB, Game, Home Network, AUX. Наличие каждого входа и соответствие
переименованным входам на конкретной прошивке нужно проверить на ресивере.

## Сетевой пульт в 0.2.0

Новые кнопки отправляют команды напрямую на TCP-порт AVR. Обучение Broadlink
для них не нужно. Точные имена команд проверены по исходникам HKAPI;
физическая поддержка каждой расширенной команды AVR 151S пока не подтверждена.

| Группа | Кнопки / значения `command` для сетевого пульта |
| --- | --- |
| Воспроизведение | `play`, `pause`, `next`, `previous` |
| Перемотка | `forward`, `reverse` |
| Навигация | `up`, `down`, `left`, `right`, `ok`, `back`, `home` |
| Дополнительные меню | `info`, `options` |
| Sleep | `sleep` |
| Звук | `mute_toggle`, `volume_up`, `volume_down` |

Play/Pause и перемотка зависят от активного источника; они не гарантируют
управление внешним HDMI-плеером. Sleep отправляет одно нажатие команды `sleep`:
число минут не задаётся и таймер не читается. После неё питание не помечается
выключенным, поскольку смысл и эффект команды не подтверждены обратной связью.

Все 17 кнопок и список входов доступны на странице устройства. Сетевой пульт
можно использовать в автоматизации, заменив пример своей сущностью:

```yaml
action: remote.send_command
target:
  entity_id: remote.harman_kardon_avr_151s_network_remote
data:
  command:
    - home
    - down
    - ok
  delay_secs: 0.4
```

Принимается не более 20 команд за вызов, задержка 0–5 секунд. Весь список
проверяется до отправки; неизвестная команда отклоняет весь вызов. При сбое
связи последовательность останавливается без повторов. Удержание кнопок и
`num_repeats` больше 1 не поддерживаются; нужные нажатия указываются в списке.

`remote.turn_on` / `remote.turn_off` также используют только Ethernet. Для
включения из глубокого сна через Broadlink используйте медиаплеер. Сетевые
кнопки, пульт и выбор входа недоступны, когда TCP недоступен.

Питание, вход, mute, громкость и состояние воспроизведения по-прежнему не
считываются с ресивера. Команда Play не означает подтверждённое состояние Playing.
Управление surround, эквалайзером и каналами не заявлено: команды не подтверждены.

### Обновление с 0.1.0

Обновите интеграцию в HACS до 0.2.0 и перезапустите HA. Если версия не видна,
включите отображение предварительных версий. Повторное добавление устройства
не требуется: настройки, идентификаторы медиаплеера и старой кнопки mute сохраняются.
Новые сущности создаются автоматически.

## Почему нужен Broadlink

У AVR 151S есть Sleep и глубокое отключение Off. В Off сетевое управление может
быть недоступно. Производитель указывает, что для выхода из полного standby
нужен штатный пульт или кнопка. Установка другой интеграции не включает
отключённый Ethernet; поддержка Wake-on-LAN для этой модели здесь не заявляется.

При `media_player.turn_on`:

1. Интеграция проверяет TCP-порт (по умолчанию 10025).
2. Если он доступен, отправляет сетевую команду `power-on`.
3. Если он недоступен, отправляет **одну** обученную ИК-команду через выбранный
   Broadlink и ждёт появления TCP, по умолчанию до 45 секунд.
4. При тайм-ауте выдаёт ошибку, не сообщает об успешном включении и не повторяет ИК-команду.

Нужна **отдельная Power On**, не Power Toggle. На штатном пульте AVR есть отдельные
кнопки включения и выключения. Сбой сети тоже может вызвать попытку ИК-включения;
отдельная Power On не должна выключать уже включённый ресивер.

## Подготовка Broadlink

Сначала добавьте Broadlink через его стандартную интеграцию HA и убедитесь,
что рядом с ресивером работает его ИК-передатчик. В «Инструменты разработчика →
Действия» выполните, заменив `remote.living_room` своей сущностью:

```yaml
action: remote.learn_command
target:
  entity_id: remote.living_room
data:
  device: harman_kardon
  command: power_on
  command_type: ir
```

Когда Broadlink перейдёт в режим обучения, направьте на него штатный пульт
и нажмите **Power On**. Для проверки:

```yaml
action: remote.send_command
target:
  entity_id: remote.living_room
data:
  device: harman_kardon
  command: power_on
```

Проверьте глазами включение ресивера. Повторите команду при включённом ресивере:
он должен остаться включённым. Коды из приложения Broadlink автоматически
не становятся обученными командами HA; обучение выполняется через HA.

## Установка сейчас: вручную

1. Сделайте резервную копию конфигурации HA.
2. Из архива скопируйте папку `custom_components/hk_avr` в
   `/config/custom_components/hk_avr`. Не переносите весь репозиторий в эту папку.
3. Перезапустите Home Assistant.
4. Откройте «Настройки → Устройства и службы → Добавить интеграцию».
5. Найдите **Harman Kardon AVR 151S**.
6. Укажите имя, IP-адрес, порт; выберите Broadlink и точные значения обученных
   `device` и `command`. Стандартные значения — `harman_kardon` и `power_on`.
7. Если ресивер спит, отдельный экран предложит сохранить непроверенное подключение.
   При настройке интеграция сама ресивер не включает.

Без Broadlink интеграция также работает, но для сохранения ресивер должен быть
доступен по TCP и включение из глубокого Off не поддерживается.

## Установка через HACS

Добавьте `https://github.com/ipmerlin/ha-harman-kardon-avr` в HACS:
«Пользовательские репозитории» → категория **Integration**. Скачайте
интеграцию, перезапустите HA и добавьте устройство описанным выше способом.
Добавление пользовательского репозитория не означает включение в основной каталог HACS.
Первый релиз предварительный: для него может потребоваться включить отображение
предварительных версий в HACS. Также доступен код из ветки `main`.

## Настройки, состояния и ограничения

- Закрепите IP ресивера в DHCP роутера. Имя и адрес можно менять через
  «Перенастроить» в меню интеграции. Идентификаторы сущностей при этом сохраняются.
- Можно убрать выбор Broadlink при перенастройке. Его интеграция не удаляется.
- Сетевой протокол не предоставляет достоверной обратной связи о питании,
  текущем входе, mute и громкости. Медиаплеер использует предполагаемое состояние
  после отправки команд, отмеченное `assumed_state` и `state_feedback: optimistic`.
- После старта состояние питания неизвестно, даже если TCP доступен. Изменения
  штатным пультом не синхронизируются. При потере Ethernet предполагаемые On и
  вход сбрасываются; потеря сети сама по себе не означает, что ресивер выключен.
- При настроенном Broadlink медиаплеер остаётся доступным для действия включения,
  даже если TCP недоступен. Это не подтверждение доступности Broadlink или питания AVR.
  Смотрите отдельный датчик Ethernet.
- Запись в TCP и успешный вызов Broadlink означают отправку, а не подтверждение
  физического выполнения. Появление TCP после ИК подтверждает сеть, не звук на выходе.
- Фоновая проверка каждые 30 секунд открывает и закрывает TCP без команд и heartbeat.
  Удержание ресивера во включённом состоянии не является целью этой проверки.
- Ошибочные сетевые команды не повторяются: повтор громкости или mute может
  изменить результат. ИК-пробуждение применяется только к явному включению.
- Встроенная интеграция `harman_kardon_avr` имеет другой домен. При переходе
  удалите её YAML-запись, если не хотите две управляющие сущности одного ресивера.
- Auto Power Off в меню ресивера влияет на переходы Sleep/Off. Настройки прошивок
  могут различаться; интеграция их не меняет.

Удаление: удалите запись интеграции через «Устройства и службы», затем удалите
пакет через HACS либо папку `hk_avr` вручную и перезапустите HA. Обученные команды
Broadlink сохраняются в его собственной интеграции.

## Проверка на реальном устройстве

После установки проверьте TCP-управление при включённом AVR, обучение Power On,
затем включение из глубокого Off. Убедитесь, что Ethernet появляется в пределах
тайм-аута. Отдельно проверьте повторное включение, mute, входы и ошибку при
перекрытом ИК-канале. Испытания должны подтверждаться экраном/звуком ресивера.

## Разработка и проверка

```sh
python scripts/check.py
python scripts/check_flows.py
python scripts/check_flows.py --voluptuous
python -m ruff check custom_components tests scripts
```

`scripts/check.py` использует стандартную библиотеку: проверяет Python/JSON,
метаданные, переводы, TCP-пакеты и автомат состояний на локальном TCP-сервере.
Он не подключается к реальному ресиверу и не подтверждает работу HA.
`check_flows.py` дополнительно проверяет логику настройки с настоящими
библиотеками схем `probatio`/`voluptuous` и минимальным адаптером API HA.
Для него установите `pip install probatio voluptuous`. Эти проверки также
не заменяют запуск настоящего HA.
Тесты `tests/ha` предназначены для Linux с настоящим HA и
`pytest-homeassistant-custom-component`; CI запускает их отдельно от offline-тестов.

Архив: `python scripts/package.py`. Генерация переводов/иконки:
`python scripts/generate_assets.py` (нужен Pillow).
