# Изменения

## 0.1.0

- Настройка и перенастройка через интерфейс HA, русский и английский языки.
- Управление AVR 151S по локальному TCP.
- Выбор Broadlink для однократного ИК-включения при недоступном Ethernet.
- Ожидание сети, явные ошибки связи и отсутствие повторов неоднозначных команд.
- Кнопка mute-toggle и диагностический датчик TCP.
- Offline-тесты и отдельные тесты для настоящего HA.

Предварительный релиз для испытаний. Локальные проверки пройдены; CI ожидает
исполнителя GitHub Actions. Работа в настоящем HA и на физическом ресивере
пока не подтверждена.
